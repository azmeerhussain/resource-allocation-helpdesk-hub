## Endpoints (base `/api/v1/assets`)

| Endpoint | Verbs | What it does |
|---|---|---|
| `/api/v1/assets` | POST, GET | Add an asset. GET does a multi-field search: `status`, `category`, `departmentProgram`, `courseId`, `labId`, `q` (name contains) |
| `/api/v1/assets/{asset_id}` | GET, PUT, DELETE | Read, update or delete an asset |
| `/api/v1/assets/{asset_id}/return` | POST | Return a checked-out physical device. Optional body `{"allocationId": "..."}`; without it, the oldest outstanding check-out is returned |
| `/api/v1/assets/allocations` | GET | Active allocations, checked-out/overdue units, voucher credit and assigned license keys for `courseId` and/or `labId` |
| `/api/v1/assets/tickets` | POST, GET | Submit a resource request ticket; list tickets filtered by `status`, `courseId`, `labId`, `projectName`, `assetId` |
| `/api/v1/assets/tickets/{ticket_id}` | GET, PUT, DELETE | Ticket details with history and metrics. PUT with `status` = approval transition (APPROVED / REJECTED / CLOSED, `reviewedBy`); PUT without `status` = edit contents (PENDING only). DELETE = delete a PENDING ticket |
| `/api/v1/assets/tickets/{ticket_id}/allocate` | POST | Allocation execution command: deducts inventory atomically from an APPROVED ticket and issues license keys, voucher codes (`VCH-…`) and hardware tokens (`HW-…`) |

Asset categories: `HARDWARE`, `LAPTOP`, `IOT_NODE` (physical), `SOFTWARE_LICENSE`, `CLOUD_VOUCHER`.
Asset status: `AVAILABLE`, `RESERVED`, `CHECKED_OUT`, `OVERDUE`. Ticket status: `PENDING`, `APPROVED`, `REJECTED`, `ALLOCATED`, `CLOSED`.

## Build, run, test

```bash
cd functional-codebase

# unit + API integration tests (in-memory H2 in PostgreSQL mode, no Docker needed)
mvn -B verify

# run the service + PostgreSQL (seeds demo assets from src/main/resources/mock-data/)
docker compose up --build -d
curl http://localhost:8080/api/v1/assets

# end-to-end smoke test against the running stack
./smoke-test.sh

docker compose down -v
```

## Example

```bash
curl -X POST localhost:8080/api/v1/assets/tickets -H 'Content-Type: application/json' -d '{
  "requesterName": "Prof. Example", "requesterRole": "INSTRUCTOR", "courseId": "CS763-F26",
  "items": [ { "assetId": "<laptop-uuid>", "quantity": 2 } ] }'
curl -X PUT  localhost:8080/api/v1/assets/tickets/<ticket-id> -H 'Content-Type: application/json' \
     -d '{"status":"APPROVED","reviewedBy":"IT Director"}'
curl -X POST localhost:8080/api/v1/assets/tickets/<ticket-id>/allocate -H 'Content-Type: application/json' \
     -d '{"allocatedBy":"IT Admin"}'
```
